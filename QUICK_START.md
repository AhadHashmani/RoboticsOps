# 🚀 RoboticsOps Quick Start Guide\n\n## Installation (2 minutes)\n\n```bash\n# 1. Navigate to project\ncd ~/RoboticsOps\n\n# 2. Create virtual environment\npython3 -m venv venv\nsource venv/bin/activate\n\n# 3. Install dependencies\npip install -r requirements.txt\n\n# 4. Setup environment\ncp .env.example .env\n# Edit .env and add your ANTHROPIC_API_KEY\n```\n\n## Running the Project\n\n### Option 1: Dashboard (Web UI) ✨\n```bash\nRUN_MODE=dashboard streamlit run frontend/app.py\n```\nOpen: http://localhost:8501\n\n**Features:**\n- Overview: Robot status & warehouse metrics\n- Robots: List all robots with real-time status\n- Tasks: View and track active tasks\n- Analytics: 30-day performance charts\n- AI Agent: Interface to Claude agent\n\n### Option 2: REST API 🔌\n```bash\nRUN_MODE=api python main.py\n```\nOpen: http://localhost:8000/docs\n\n**Available Endpoints:**\n- `GET /robots` - List all robots\n- `GET /robots/{robot_id}` - Get specific robot\n- `POST /robots/{robot_id}/assign` - Assign task\n- `GET /warehouse/metrics` - Warehouse KPIs\n- `GET /health` - Health check\n\n### Option 3: AI Agent 🤖\n```bash\nRUN_MODE=agent python main.py\n```\n**Features:**\n- Multi-turn conversations with Claude\n- Tool use for robot control\n- Real-time status queries\n- Task optimization\n- Type `exit` to quit\n\n**Example Commands:**\n```\n📦 Warehouse Command: What's the status of AGV-001?\n📦 Warehouse Command: Assign a pick task to the fastest available robot\n📦 Warehouse Command: How long to complete all pending tasks?\n📦 Warehouse Command: exit\n```\n\n## Testing\n\n```bash\n# Run all tests\npytest tests/\n\n# Run specific test file\npytest tests/test_agent.py -v\n\n# Run with coverage\npytest tests/ --cov=agent,backend\n```\n\n## Docker Deployment\n\n```bash\n# Build and run all services\ndocker-compose -f docker/docker-compose.yml up -d\n\n# View logs\ndocker-compose -f docker/docker-compose.yml logs -f\n\n# Stop services\ndocker-compose -f docker/docker-compose.yml down\n```\n\n## Project Structure\n\n```\nagent/          → Claude AI orchestration\nbackend/        → FastAPI REST API\nfrontend/       → Streamlit dashboard\nconfig/         → Configuration management\ngraphics/       → WIPE OpenGL integration\ndocker/         → Containerization\nisaac_sim/      → NVIDIA Isaac Sim\ntests/          → Unit & integration tests\n```\n\n## Module Reference\n\n### agent/orchestration.py\n- `RoboticsAgent` class: Main AI agent\n- Methods: `start()`, `_get_agent_response()`, `_execute_tool()`\n- Tools: query_robot_status, assign_task_to_robot, get_warehouse_layout, predict_completion_time\n\n### backend/api.py\n- `create_app()`: FastAPI application factory\n- Models: `Robot`, `Task`, `Warehouse`\n- Endpoints: /robots, /tasks, /warehouse/metrics, /health\n\n### frontend/app.py\n- Streamlit web interface\n- Views: Overview, Robots, Tasks, Analytics, AI Agent\n- Widgets: Metrics, charts, dataframes, inputs\n\n### config/__init__.py\n- `ConfigManager` class: Loads robot configs & warehouse layout\n- `get_config()`: Get global config instance\n\n## Environment Variables\n\n```env\nRUN_MODE=dashboard              # dashboard, api, or agent\nDEBUG=True\nAPI_HOST=0.0.0.0\nAPI_PORT=8000\nDB_HOST=localhost\nDB_PORT=5432\nANTHROPIC_API_KEY=sk-ant-...    # Required for agent mode\nWAREHOUSE_WIDTH=100\nWAREHOUSE_HEIGHT=50\nNUM_ROBOTS=4\nLOG_LEVEL=INFO\n```\n\n## Troubleshooting\n\n**Issue: \"Module not found\" errors**\n```bash\npip install -r requirements.txt\n```\n\n**Issue: ANTHROPIC_API_KEY not set**\n```bash\nexport ANTHROPIC_API_KEY=sk-ant-your-key-here\n# OR add to .env file\n```\n\n**Issue: Port already in use**\n```bash\n# Change port in .env and main.py\nAPI_PORT=8001\n```\n\n**Issue: Docker build fails**\n```bash\ndocker-compose -f docker/docker-compose.yml down\ndocker-compose -f docker/docker-compose.yml up --build\n```\n\n## Performance Tips\n\n- **Agent**: ~2 seconds per decision (varies with API response time)\n- **Dashboard**: Real-time updates (50ms refresh rate)\n- **API**: Sub-100ms response times\n- **Robot simulation**: 60 FPS with 4 concurrent robots\n\n## Next Steps\n\n1. ✅ Install dependencies\n2. ✅ Set ANTHROPIC_API_KEY\n3. ✅ Run dashboard to see UI\n4. ✅ Test API with
